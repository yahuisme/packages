# WiFi 7

面向 OpenWrt / ImmortalWrt 的 LuCI 无线管理应用，适配 W1700K 的 MT7996 三频与 MLO 使用场景。

入口：**网络 → WiFi 7**。

## 功能

- **射频状态**：显示运行状态、信道、发射功率、信道占用率与 DFS 状态。
- **射频设置**：读取驱动提供的信道与频宽能力，保留已有配置；管理启用状态、发射功率及背景雷达。只提交变化字段，应用成功后刷新配置基线与信道列表；可能中断连接的更改需确认。
- **MLO**：统一管理 MLO 接口，默认仅显示 MLO 配置；普通无线接口仍由原生“无线”页面管理。
- **已连接客户端**：按需加载，进入标签后才采集关联信息；按客户端折叠显示 SSID、协议和连接时长，展开查看各 MLO 链路的频段、信号及收发速率。
- **按需诊断**：点击后导出无线运行信息和有限日志，不启动常驻服务、不写入闪存。分享前请检查并遮盖 SSID、MAC 等隐私信息。

采集失败或驱动未提供的数据不等于零；无法确认的状态不会显示为“已解锁”或“CAC 已通过”。配置保存成功仅表示配置事务完成，不代表驱动已经实现对应射频状态。

## 使用说明

将本包加入固件软件源，选择 `luci-app-wifi7`。启用简体中文时，由 LuCI 构建规则选择随包翻译。

独立安装时应使用与目标固件 ABI、软件源和包管理器匹配的软件包，并安装声明的依赖。更新后若仍显示旧界面，使用无痕窗口核对，再检查实机静态资源是否来自本次构建。

无线参数修改可能导致连接中断，建议通过有线网络操作。信道、频宽及功率仍受驱动能力和适用监管限制约束；本应用不保证解除硬件功率限制。

## 验证边界

本地回归测试使用明确构造的输入验证 RPC 数据处理、文本解析与异常分支，不代替实机验证。驱动、`iw`、hostapd 的 MLO 数据支持以目标固件实际输出为准。
