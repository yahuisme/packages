# luci-app-firmwareupgrade

OpenWrt / ImmortalWrt 专属极简、安全、现代的固件在线升级插件。

## 功能特性

- **现代 LuCI 架构**：纯异步 JavaScript 视图，页面秒开无阻塞卡顿；完美契合 Aurora / Argon 主题与 8pt 栅格规范。
- **智能自适应引擎**：自动识别机型架构与固件变体（如 W1700K `ubi2` / `ubi2-oc`、Linksys MX4200 `v1` / `v2` 及通用机型），精准匹配 GitHub Release 资产。
- **双重安全防呆校验**：
  1. **哈希校验**：自动校验 GitHub API 返回的 SHA256 或 Release 附带的 `sha256sums`。
  2. **兼容性预检**：刷写前自动执行 `sysupgrade -T` 兼容性干跑校验，非法镜像拒绝刷写。
- **升级模式自选**：支持「全新升级（不保留配置）」与「保留配置升级」。
- **升级监控与心跳探针**：下载与校验进度实时反馈，刷机重启后自动探测网关连通性并重定向登录。
- **规范菜单位置**：置于 `系统 -> 固件升级`（位于官方「备份与升级」正下方，order: 71）。

## 菜单路径

- **英文**：`System` -> `Firmware Upgrade`
- **中文**：`系统` -> `固件升级`
